# SG Photography

An Astro-powered photography portfolio site for Sally Gao Photography.

## Overview

This project is a static website focused on showcasing photography work, service information, and client gallery pages. It is built with Astro, TypeScript, GSAP, and Lenis.

## Tech Stack

- Astro
- TypeScript
- GSAP
- Lenis

## Getting Started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

The site is configured as a static Astro project and can be deployed easily to platforms like Vercel or Netlify.
